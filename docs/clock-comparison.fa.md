# مقایسهٔ ساعت سایت‌ها با ویندوز

این ابزار فقط ثانیه‌نمای DOM را با ساعت میزبان مقایسه می‌کند. به حساب یا API سفارش متصل نمی‌شود، کلیک نمی‌کند، credential نمی‌خواند و ساعت ویندوز را تغییر نمی‌دهد. هدف، تشخیص تفاوت نمایش، جهش، توقف و تغییر پس از بازخوانی است. زمان نمایش، ساعت سرور، دریافت کارگزاری و پذیرش هسته شواهد متفاوتی دارند.

`data_collector/clock_display_probe.mjs` یک مشاهده‌گر محدود به ۶۰ ثانیه و حداکثر ۸ گرهٔ ساعت است. در گردش فعلی از بازه‌های ۸ ثانیه‌ای استفاده می‌شود. تایمرها و MutationObserver در پایان همان مشاهده حذف می‌شوند و global صفحه تغییر نمی‌کند. متن ذخیره‌شده فقط رشتهٔ ساعت در selector ازقبل مشاهده‌شده است.

`scripts/clock_compare_cua.mjs` فقط داخل Browser/CUA مجاز و با handleهای فعلی تب‌ها استفاده می‌شود. مرورگر دیگری attach نمی‌کند. باید ابتدا فهرست تب‌ها و selector واقعی ساعت بررسی شوند؛ CSS hash، نسخهٔ سایت و وضعیت login ممکن است عوض شوند. در کاریزما زمان آخرین معامله را با ساعت زنده اشتباه نگیرید. در time.ir حالت AM/PM را هم از همان ناحیهٔ ساعت بخوانید. در TSETMC ساعت بورس و فرابورس جدا ثبت می‌شوند.

پس از دریافت handleهای موجود و capability مستند `cdp` برای هر تب، فراخوانی داخل همان REPL:

```javascript
const comparison = await import('file:///ABSOLUTE_WORKSPACE/scripts/clock_compare_cua.mjs');
const result = await comparison.compareClockTabs(observedSpecifications, {
  workspace: absoluteWorkspacePath,
  rounds: 3,
  durationMs: 8000,
});
```

هر specification شامل `site`، `cdp`، `selector`، `tabId`، `url` و `fresh` است؛ این‌ها از مشاهدهٔ همان نوبت می‌آیند. این فایل یک CLI اتصال به مرورگر نیست و در مرورگر یا DevTools کاربر paste نمی‌شود. تحلیل، متن اولیهٔ بدون مشاهدهٔ تغییر ثانیه را به‌عنوان مرز ثانیه حساب نمی‌کند، ارقام فارسی/عربی و عبور از نیمه‌شب را می‌فهمد، تغییرات گذرای زیر ۵۰ms را در خلاصه کنار می‌گذارد و جهش‌ها را جدا ثبت می‌کند. همهٔ نمونه‌های خام حفظ می‌شوند.

عدد `appearance_lag_median_ms` یعنی دیر ظاهرشدن برچسب ثانیه نسبت به آغاز همان ثانیه در ویندوز؛ عدد مثبت، عقب‌بودن **نمایش** را نشان می‌دهد. این عدد، offset خالص سرور یا تأخیر پردازش سفارش نیست. مشاهدهٔ DOM نیز زمان اسکن پیکسل یا دیدن چشم انسان را اندازه نمی‌گیرد.

برای برداشت فقط‌خواندنی ویندوز و نمونه‌های NTP:

```powershell
powershell.exe -NoProfile -File .\scripts\clock_reference_snapshot.ps1 -Samples 5
```

اسکریپت از منبع فعلیِ شناخته‌شده و سرویس عمومی آزمایشی time.ir نمونهٔ stripchart/rdtsc می‌گیرد؛ هیچ `resync`، تغییر رجیستری یا restart انجام نمی‌دهد. کد خروج صفرِ w32tm کافی نیست؛ تعداد ردیف‌های موفق و خطاهای متن باید بررسی شوند. offset شبکه با قطعیت خطای UTC برابر نیست.

خروجی‌ها، گزارش و manifest زیر `data/private/clock-comparison/` می‌مانند. دادهٔ حساب، عکس حساب و اطلاعات مالی وارد مستندات عمومی یا fixture نمی‌شوند. دادهٔ نمونهٔ ساختگی فقط در tests است.

برای جلسهٔ تازه، حدود ۰۸:۴۰ وضعیت ویندوز و سه دور هم‌زمان گرفته شود؛ نزدیک ۰۸:۴۳ یک برداشت تازه انجام شود. هر reload، تغییر فوکوس، visibility، timeout یا تغییر ساعت می‌تواند نتیجه را عوض کند. هیچ عددی از شب قبل به‌صورت خودکار برای جلو/عقب‌انداختن اقدام مالی به کار نمی‌رود. برنامهٔ ثبت یا کلیک مالی فعال نمی‌شود.

آزمون‌های مرتبط:

```powershell
node --test tests/clock_display_probe.test.mjs tests/clock_compare_cua.test.mjs
```

نتیجهٔ ۲۴ اکتبر ۲۰۲۶ در گزارش خصوصی `comparison-2026-10-24.fa.md` و دادهٔ ساختاریافتهٔ هم‌نام نگهداری شده است. آن مشاهده برای مقایسهٔ همان دستگاه و همان بازه است؛ دربارهٔ دقت داخلی هسته یا روز بعد تضمین نمی‌دهد.
