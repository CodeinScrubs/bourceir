# بررسی وابستگی‌های انتشار ۰٫۷٫۵۲

در ۱۴ نوامبر ۲۰۲۶، نسخه‌های قفل‌شدهٔ محیط پایه و آموزش CPU برای Python 3.11 روی Windows و
Linux با API عمومی OSV بررسی شدند. این بررسی فقط نام و نسخهٔ بسته‌های عمومی را ارسال کرد؛
اطلاعات حساب، دیتابیس و کلیدها ارسال نشدند.

## یافته و اصلاح

| بسته | قفل پیشین | قفل انتشار | دلیل |
| --- | --- | --- | --- |
| certifi | 2026.7.22 | 2026.10.23 | حذف ریشه‌های emSign مرتبط با رخداد کلید واسط؛ حداقل نسخهٔ اصلاح‌شده 2026.10.18 است |
| Pillow | 12.3.0 | 13.0.0 | رفع هشدارهای ثبت‌شدهٔ پردازش تصویر، از جمله TIFF |
| Streamlit | 1.65.0 | 1.67.0 | نسخهٔ قبلی Pillow را به کمتر از ۱۳ محدود می‌کرد؛ نسخهٔ تازه رسماً بازهٔ کمتر از ۱۴ را می‌پذیرد |

مبنای اصلاح: [اطلاعیهٔ اصلی certifi](https://github.com/certifi/python-certifi/security/advisories/GHSA-6q48-6c7w-9gw2)،
[اطلاعیهٔ اصلی TIFF در Pillow](https://github.com/python-pillow/Pillow/security/advisories/GHSA-xcvg-w56q-r89m)،
[انتشار Pillow 13](https://github.com/python-pillow/Pillow/releases/tag/13.0.0) و
[فرادادهٔ رسمی Streamlit 1.67](https://pypi.org/pypi/streamlit/1.67.0/json).

در فایل ورودی، حداقل نسخهٔ امن نیز ثبت شد تا بازسازی قفل به نسخهٔ آسیب‌پذیر برنگردد.
فایل قفل با resolver دوباره ساخته شد؛ override ناسازگار استفاده نشد. NumPy، pandas،
scikit-learn و Gymnasium تغییر نسخه نداشتند. `httptools` و `toml` که Streamlit تازه دیگر
وابستگی آن‌ها را اعلام نمی‌کند، از قفل خارج شدند؛ فایل‌ها و داده‌های کاربر حذف نشدند.

بررسی دوبارهٔ ۶۳ بستهٔ منطبق با این دو محیط و پروفایل، در پاسخ کامل OSV هشدار شناخته‌شده‌ای
برنگرداند. این نتیجه، ممیزی کدِ تمام وابستگی‌ها، اثبات نبود آسیب‌پذیری یا تضمین امنیت آینده
نیست. [قرارداد پرس‌وجوی OSV](https://google.github.io/osv.dev/post-v1-querybatch/).

## دامنهٔ اعتبارسنجی

اجرای ناقص آزمون‌های پیش از ارتقا به‌عنوان موفق منتشر نمی‌شود. رسید آن با علت توقف محفوظ است.
آزمون کامل انتشار باید از نو، با قفل تازه و منابع ثابت، تمام شود. کنترل نصب از ZIP، نمایش
داشبورد و `pip check` نیز باید با محیط تازه سنجیده شوند؛ شمار و نتیجهٔ واقعی در
[گزارش انتشار](../releases/0.7.52-fa.md) ثبت می‌شوند.
