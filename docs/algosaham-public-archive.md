# آرشیو و نقشهٔ عمومی الگوسهام

برداشت HTML با شناخت منطق کامل سایت متفاوت است. ابزار `archive-site` نقشه سایت، پیوندهای همان مبدأ و JavaScript عمومی ارجاع‌شده را با فاصله درخواست و رعایت robots حفظ می‌کند. کد ناشناس را در Python اجرا نمی‌کند؛ مسیر ورود، حساب، پرداخت، API و نشانی دارای query را دنبال نمی‌کند. HTTP 429/503 برداشت را متوقف می‌کند. بودجه صفحه و نقشه سایت محدود است. URL فارسی و درصدگذاری‌شده یکسان می‌شوند و مسیر دوبار درصدگذاری‌شده دنبال نمی‌شود.

```powershell
.venv/Scripts/python.exe brs.py archive-site --url https://algosaham.ir/ --output data/private/algosaham-public --max-pages 4000 --interval 1
.venv/Scripts/python.exe brs.py catalog-sources --site data/private/algosaham-public
.venv/Scripts/python.exe brs.py catalog-sources --files "مسیر فایل متن.txt" --output data/private/source-catalog
```

ادامه، منابع موفق محفوظ را دوباره دریافت نمی‌کند و هش بدنه‌های قبلی را کنترل می‌کند. زمان هر مشاهده مستقل است؛ این برداشت چنددقیقه‌ای/چندساعته، عکس هم‌زمان بازار نیست. یک قفل آرشیو مانع دو نویسنده هم‌زمان است. روی فایل‌های دریافت‌شده تغییر داده نمی‌شود؛ صورت منابع فقط افزوده می‌شود. برای مشاهده تازه تمام صفحات، آرشیو تازه بسازید.

خروجی‌ها: `sources.jsonl` (منبع/زمان/وضعیت/هش)، بدنه و متن فشرده، `coverage.json` (پوشش و نشانی‌های حل‌نشده)، `knowledge-catalog.json` و `knowledge-map-fa.md`. فایل متنیِ استخراج‌شده مرجع اعتماد مستقل نیست؛ فهرست‌ساز متن را از بدنه دارای هش بازسازی می‌کند. وجود نشانی یک سرویس در JavaScript فقط «ارجاع موجود در کد عمومی» است؛ اثبات فراخوانی موفق یا دسترسی به پشت‌صحنه نیست.

منابع مفید و جایگاهشان در BRS:

| بخش | نشانی | استفاده قابل دفاع |
|---|---|---|
| آموزش JavaScript | [آموزش فیلترها](https://algosaham.ir/dashboard/filters) | خواندن تعریف و کد آموزشی؛ بررسی واحد/مخرج/زمان و تبدیل به فرضیه آزمون‌پذیر |
| آموزش Python | [آموزش پایتون](https://algosaham.ir/dashboard/python-filters) | مقایسه تعریف‌ها؛ کد ناشناس خودکار اجرا یا نصب نمی‌شود |
| فیلترهای کاربران | [فهرست عمومی](https://algosaham.ir/dashboard/public-filters) | عنوان و خروجی قابل مشاهده؛ بازدید و رأی کاربران، آزمون سود نیست |
| پول داغ | [راهنمای پول داغ](https://algosaham.ir/dashboard/hot-money/guide) | شناخت تعریف شاخص؛ تخمین «بازیگر» یا هویت معامله‌گر را حقیقت فرض نمی‌کنیم |
| بازی بازار | [راهنمای بازی بازار](https://algosaham.ir/dashboard/market-game/guide) | ایدهٔ نمایش رفتار؛ جای دفتر تصمیم و نتیجه مستقل BRS نیست |
| ابزار AI | [راهنمای فیلتر AI](https://algosaham.ir/ai-filter/guide) | الهام برای رابطِ قرارداد قابل بررسی؛ اجرای کد دلخواه در BRS مجاز نیست |
| نماد و نمای کلی | پیوندهای `Namad` و `glance` | اطلاعات عمومی مشاهده‌شده؛ منبع اصلی قیمت و هویت BRS همچنان TSETMC است |
| اختیار/طلا | بخش‌های اختصاصی سایت | شناخت مرز سایت؛ این ابزارها به جامعه سهام عادی BRS اضافه نمی‌شوند |

نمونهٔ بررسی مستقیم: [حجم مشکوک](https://algosaham.ir/dashboard/filters/hajm-mashkook) حجم امروز را با میانگین ده روز گذشته مقایسه می‌کند، با آستانه انتخابی سه، بیش از صد معامله و بیش از پنج میلیارد **ریال** ارزش معاملات. این با `tvol > 3*bvol` یکی نیست؛ bvol حجم مبناست. محاسبه خالص حقیقی در کد آموزشی از حجم تفاضلی × VWAP استفاده می‌کند؛ ارزش واقعی جداگانه خرید/فروش حقیقی را اثبات نمی‌کند. BRS باید کیفیت سرانه ارزشی/حجمی و تخمینی بودن ارزش را حفظ کند.

برخی صفحات عمومی در HTTP فقط پوسته دارند، در مرورگر نتیجه جاری را بارگذاری می‌کنند و کد فرمول را نشان نمی‌دهند. بنابراین پوشش sitemap، پوشش فرمول‌ها نیست. فرمول خصوصی، منبع تمام داده‌ها، کیفیت سرویس پشت‌صحنه و سودآوری بدون شواهد مستقل نامعلوم می‌مانند. ورود، دور زدن دسترسی یا کپی ادعای سود به عنوان سیگنال در این کار انجام نمی‌شود.

## قرارداد زمان و اجرای کد آموزشی

راهنمای فعلی Python دو حالت دارد: عبارت نهایی بولی برای هر نماد، و `result` شامل نماد/شناسه برای کل بازار. به گفته راهنما، خطای یک نماد آن را از خروجی تک‌نماد حذف می‌کند؛ BRS این رفتار را برای آمار کیفیت کپی نمی‌کند، چون نامعلوم نباید بی‌صدا از مخرج حذف شود. محیط سایت برخی توابع و کتابخانه‌ها را تزریق می‌کند؛ نبود `import` در قطعه آموزشی به‌تنهایی اثبات خطای همان قطعه در محیط میزبان نیست.

`ih` تاریخچه خام و `it` تاریخچه تعدیل‌شده است؛ `wh`/`wt` تاریخچه هفتگی و `ic` آمار حقیقی/حقوقی‌اند. طبق راهنمای قابل مشاهده، اندیس صفر جدیدترین ردیف موجود است و پس از تازه‌سازی ممکن است خود امروز باشد. کد بعضی مثال‌ها با مقایسه آمار تابلو و ردیف اول، offset را تغییر می‌دهد؛ در BRS باید تاریخ واقعی و زمان دسترسی معلوم باشد، نه تشخیص برابری چند عدد. تاریخچه تعدیل‌شده سایت ورودی خودکار فیچرهای BRS نیست. اندیس ناموجود یا منفی، و قطعه تاریخچه دارای `None`، نیازمند قرارداد صریح است؛ صفر جایگزین مقدار گمشده نمی‌شود.

راهنمای پول داغ، نمونه‌برداری عادی ۱۵ ثانیه و پلاس ۵ ثانیه را توصیف می‌کند؛ چرخه نمایش/ارسال حدود ۱۵ ثانیه است. تغییر حجم و تعداد × قیمت لحظه‌ای و تجمیع دوره‌های بدون تغییر تعداد، مشاهده مستقل تک‌سفارش یا هویت یک خریدار نیست. تعریف مبلغ، دوره نمونه‌برداری و کامل بودن هر بازه باید کنار آن حفظ شود. این توضیح منبع است؛ صحت سرویس در تمام بازار یا کارایی معاملاتی آن را ثابت نمی‌کند.

برای کتاب فیلتر ضمیمه، `catalog-sources` شماره بخش، خط، هش و نشانه‌های نیازمند بررسی ثابت را ثبت می‌کند. علامت‌گذاری regex، کامپایلر یا تأیید معنایی همه فیلترها نیست؛ خواندن و آزمودن هر تعریف پیش از استفاده لازم است. اعداد گمشده، فرمول تخمینی و ادعای «پول هوشمند» نباید به داده قطعی یا سیگنال تبدیل شوند.
