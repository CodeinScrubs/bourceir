# ارزش‌گذاری فرضی سهم و حق‌تقدم

`brs.py rights-mark --spec path.json` یک سناریوی توصیفی را حساب می‌کند؛ هیچ حساب، سفارش،
توصیه یا سیگنالی نمی‌خواند و نمی‌سازد. بودجه شامل کارمزد خرید است. نسبت حق از تعداد سهم قدیم و
حق جدید ورودی محاسبه و برای سناریو به پایین گرد می‌شود. گردکردن و استحقاق واقعی حساب باید جدا
با کارگزار و ناشر تطبیق یابد. مظنه سهم و حق باید هر دو تاریخ دقیق ارزش‌گذاری داشته باشند؛
زمان هم‌زمان مشاهده و اصالت قیمت با این تابع اثبات نمی‌شود. اعداد ورودی و خروجی ریال‌اند.

مقدار علامت‌گذاری‌شده برابر نقد باقی‌مانده، ارزش سهم و ارزش حق است؛ سود نقدی و اقدامات
شرکتی دیگر را شامل نمی‌شود و فروش واقعی نیست. اگر `assumed_sale_fee_rate` برابر `null` باشد،
ارزش فروش فرضی نامعلوم می‌ماند؛ اگر نرخ داده شود، فرض فروش هر دو دارایی با همین نرخ و همان
قیمت است. صف، توقف، اجرای بخشی، ثبت یا اعتبار حق و جزئیات کارمزد اثبات نمی‌شوند.

```json
{
  "symbol": "الف", "rights_symbol": "الفح",
  "budget_rial": 10000, "purchase_date": "2024-01-01", "purchase_price_rial": 100,
  "purchase_fee_rate": "0.01", "old_shares": 4, "new_rights": 3,
  "valuation_date": "2024-02-01", "share_quote_date": "2024-02-01", "share_quote_rial": 80,
  "rights_quote_date": "2024-02-01", "rights_quote_rial": 30, "assumed_sale_fee_rate": "0.02"
}
```

نرخ‌ها به صورت رشته اعشاری‌اند؛ برای مثال `0.01` یعنی یک درصد. داده مثال بالا فقط برای شرح
قرارداد است و در پایگاه عملیاتی ذخیره نمی‌شود. قرارداد فقط یک اقدام حق‌تقدم را پشتیبانی می‌کند.
