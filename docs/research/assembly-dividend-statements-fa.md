# خواندن سود مصوب در تصمیمات، خلاصه و اصلاحیه مجمع

`core.assembly_dividend.primary_assembly_dividend` فقط رقم صریح «سود نقدی هر سهم
(ریال)» را از متن نمایان تصمیمات یا خلاصه تصمیمات مجمع عادی سالیانه می‌خواند.
EPS، جدول کل شرکت با واحد میلیون ریال، خانه خالی و تصمیم افزایش سرمایه جانشین آن نیستند.
صفر فقط وقتی شناخته‌شده است که صریحاً در همان سطر مقدار درج شده باشد.

تاریخ مجمع فقط در بخش «الف ـ زمان و محل برگزاری مجمع عمومی» تا «ب ـ دستور جلسه»
جست‌وجو می‌شود. تاریخ اشاره‌شده در علت اصلاح، تاریخ یک جلسه دیگر نیست. متن و عنوان
باید از نظر نوع گزارش، نام شرکت، نماد و سال مالی سازگار باشند. اصلاحیه باید شماره
پیگیری نسخه قبلی را صریحاً اعلام کند؛ تابع شماره و برچسب اصلاحیه را نگه می‌دارد.
تاریخ مجمع جایگزین زمان اظهارشده انتشار اصلاحیه نمی‌شود.

تاریخ مجمع، پایان سال مالی و انتشار پیش از خواندن رقم سود با مرز توسعه کنترل می‌شوند.
نامعلوم، نسخه متعارض، متن ناقص یا واحد دیگر خروجی مالی معتبر نمی‌سازد. این تابع، قرارداد
و نسخه قدیمی `core.dividend_reconciliation` یا آرشیوهای تطبیق آن را عوض نمی‌کند.

نمونه فراخوان روی متن واقعیِ محفوظ و فراداده همان اطلاعیه:

```python
from core.assembly_dividend import primary_assembly_dividend

fact = primary_assembly_dividend(visible_text, notice, end_exclusive=holdout_start)
```

`notice` باید `tracing_no`، `symbol_fa`، `company_name`، `title` و زمان منطقه‌دار
`published_at` داشته باشد. برای بازبینی، هش متن، اطلاعیه، کد و زمان دریافت را مستقل
نگه دارید. متن گزیده مرورگر باید صریحاً از دریافت بومی HTTP و متن کامل تفکیک شود؛
گزیده، هویت بایتی پاسخ اصلی یا کامل‌بودن گزارش را اثبات نمی‌کند.

دریافت سند عمومی، تغییرمسیر رسمی `Decision.aspx` به `Reports/Assembly.aspx` را
می‌پذیرد. مسیر `Assembly.aspx` خارج از `Reports`، میزبان دیگر و پیوند نشست همچنان
رد می‌شوند. هیچ کوکی، توکن یا کنترل کپچایی به این قابلیت اضافه نشده است.

در بررسی ۲۶ اکتبر ۲۰۲۶، اصلاحیه تصمیمات حکشتی سود ۱٬۱۰۰ ریال و خلاصه تصمیمات وبصادر
سود ۱۷ ریال را صریحاً نشان دادند. متن اصلاحیه حکشتی می‌گوید نسخه قبلی رقم سود را درج
نکرده بود. این مشاهده، زمان دسترسی تاریخی مدل یا وصول وجه دارنده را اثبات نمی‌کند.
دریافت مستقل HTTP حکشتی timeout شد؛ شاهد آن گزیده قابل مشاهده مرورگر است. وبصادر
به‌صورت متن نمایان پاسخ عمومی همراه رسید و هش محفوظ شد.

خروجی این خوانش، رقم مصوب است. تعداد سهم واقعی دارنده، استحقاق، تاریخ پرداخت، وجه
قابل خرج، بازده اقتصادی و مجوز سیگنال همچنان نیازمند شواهد مستقل‌اند. `feature_eligible`،
`accepted_for_signals` و `profitability_proven` در این قرارداد همیشه False هستند.
