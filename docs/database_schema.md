# ساختار جداول پایگاه داده BRS (Database Schema)

پایگاه داده سامانه در مسیر `data/brs.db` به صورت SQLite ذخیره می‌شود و شامل جداول زیر است:

## ۱. جدول `symbols` (فهرست نمادها)
| ستون | نوع | توضیحات |
| :--- | :--- | :--- |
| `id` | INTEGER PK | شناسه یکتای داخلی |
| `tse_code` | TEXT UNIQUE | کد بین‌المللی ISIN نماد (مانند IRO1FOLD0001) |
| `symbol_fa` | TEXT | نام نماد به فارسی (مانند فولاد) |
| `name_fa` | TEXT | نام کامل شرکت |
| `market` | TEXT | بازار (bourse یا farabourse) |
| `instrument_type` | TEXT | نوع ابزار (پیش‌فرض stock) |
| `is_active` | BOOLEAN | فعال بودن در معاملات |

## ۲. جدول `daily_prices` (کندل‌های روزانه)
| ستون | نوع | توضیحات |
| :--- | :--- | :--- |
| `id` | INTEGER PK | شناسه |
| `symbol_id` | INTEGER FK | ارجاع به جدول symbols |
| `date` | TEXT | تاریخ معامله به فرمت YYYY-MM-DD |
| `open` | REAL | قیمت بازگشایی (ریال) |
| `high` | REAL | بیشترین قیمت روز (ریال) |
| `low` | REAL | کمترین قیمت روز (ریال) |
| `close` | REAL | قیمت آخرین معامله (ریال) |
| `adj_close` | REAL | قیمت پایانی تعدیل‌شده (ریال) |
| `volume` | INTEGER | حجم معاملات (تعداد سهام) |
| `value` | REAL | ارزش معاملات (ریال) |
| `trade_count` | INTEGER | تعداد دفعات معامله |
| `price_unit` | TEXT | واحد قیمت (همیشه Rial) |
| `source` | TEXT | منبع داده |
| `UNIQUE(symbol_id, date, source)` | | جلوگیری از درج تکراری |

## ۳. جدول `snapshots` (اسنپ‌شات‌های دوره‌ای تابلو)
اطلاعات مربوط به وضعیت صفوف خرید و فروش، قیمت لحظه‌ای و رفتار معامله‌گران حقیقی و حقوقی در طول بازار.

## ۴. جدول `intraday_trades` (ریزمعاملات درون‌روزی)
ریزمعاملات تیک‌به‌تیک جهت ساخت استراتژی‌های نوسان‌گیری درون‌روزی و اسکالپ (ساعت معامله، قیمت، حجم و سمت خریدار/فروشنده).

## ۵. جدول `corporate_actions` (اقدامات شرکتی)
ثبت سوابق افزایش سرمایه، تقسیم سود نقدی (DPS) و ضرایب تعدیل قیمت سهام.

## ۶. جدول `market_calendar` (تقویم بازار بورس)
تعیین روزهای کاری و تعطیلات رسمی و غیررسمی بازار بورس تهران.

## ۷. جدول `collection_log` (لاگ چرخه‌های جمع‌آوری داده)
پایش موفقیت و خطاهای دریافت داده در هر بار اجرای اسکریپت‌ها.
