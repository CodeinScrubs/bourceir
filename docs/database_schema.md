# ساختار جداول پایگاه داده BRS (Database Schema)

پایگاه داده سامانه در مسیر `data/brs.db` به صورت SQLite ذخیره می‌شود و شامل جداول زیر است:

## ۱. جدول `symbols` (فهرست نمادها)
| ستون | نوع | توضیحات |
| :--- | :--- | :--- |
| `id` | INTEGER PK | شناسه یکتای داخلی |
| `tse_code` | TEXT UNIQUE | کد بین‌المللی ISIN نماد (مانند IRO1FOLD0001) |
| `symbol_fa` | TEXT | نام نماد به فارسی (مانند فولاد) |
| `name_fa` | TEXT | نام کامل شرکت |
| `market` | TEXT | بازار (bourse یا farabourse) |
| `instrument_type` | TEXT | نوع ابزار (پیش‌فرض stock) |
| `is_active` | BOOLEAN | فعال بودن در معاملات |

## ۲. جدول `daily_prices` (کندل‌های روزانه و Point-in-Time)
| ستون | نوع | توضیحات |
| :--- | :--- | :--- |
| `id` | INTEGER PK | شناسه |
| `symbol_id` | INTEGER FK | ارجاع به جدول symbols |
| `date` | TEXT | تاریخ معامله به فرمت YYYY-MM-DD |
| `open_raw` | REAL | قیمت بازگشایی خام روز معامله (بدون تعدیل) |
| `high_raw` | REAL | بیشترین قیمت خام روز معامله (بدون تعدیل) |
| `low_raw` | REAL | کمترین قیمت خام روز معامله (بدون تعدیل) |
| `close_raw` | REAL | آخرین معامله خام روز معامله (بدون تعدیل) |
| `open` | REAL | قیمت بازگشایی |
| `high` | REAL | بیشترین قیمت روز |
| `low` | REAL | کمترین قیمت روز |
| `close` | REAL | قیمت آخرین معامله |
| `adj_close` | REAL | قیمت پایانی تعدیل‌شده |
| `adjustment_factor` | REAL | ضریب تعدیل قیمت به دلیل افزایش سرمایه یا مجمع |
| `volume` | INTEGER | حجم معاملات (تعداد سهام) |
| `value` | REAL | ارزش معاملات (ریال) |
| `trade_count` | INTEGER | تعداد دفعات معامله |
| `price_unit` | TEXT | واحد قیمت (همیشه Rial) |
| `source` | TEXT | منبع داده |
| `UNIQUE(symbol_id, date, source)` | | جلوگیری از درج تکراری |

## ۳. جدول `snapshots` (اسنپ‌شات‌های دوره‌ای تابلو)
اطلاعات مربوط به وضعیت صفوف خرید و فروش، مظنه‌های ۵ گانه، قیمت لحظه‌ای و رفتار معامله‌گران حقیقی و حقوقی در طول بازار.

## ۴. جدول `features_daily` (انبار ویژگی‌های روزانه - Feature Store)
مرجع متمرکز فاکتورهای تکنیکال و بازار (بازدهی، نوسان‌پذیری ۲۰ روزه، ATR، RSI، نسبت حجم و ورود پول هوشمند).

## ۵. جدول `features_intraday` (انبار ویژگی‌های درون‌روزی - Feature Store)
مرجع متمرکز شاخص‌های اسکالپ لحظه‌ای (قدرت خریدار، فشار صفوف، عدم تعادل سفارشات و شتاب حجم).

## ۶. جدول `intraday_trades` (ریزمعاملات درون‌روزی)
ریزمعاملات تیک‌به‌تیک جهت ساخت استراتژی‌های نوسان‌گیری درون‌روزی و اسکالپ (ساعت معامله، قیمت، حجم و سمت خریدار/فروشنده).

## ۷. جدول `corporate_actions` (اقدامات شرکتی)
ثبت سوابق افزایش سرمایه، تقسیم سود نقدی (DPS) و ضرایب تعدیل قیمت سهام.

## ۸. جدول `market_calendar` (تقویم بازار بورس)
تعیین روزهای کاری و تعطیلات رسمی و غیررسمی بازار بورس تهران.

## ۹. جدول `data_quality_metrics` (ارزیابی کیفیت داده‌ها)
ثبت رتبه سلامت داده‌ها، درصد کامل بودن و هشدارهای جهش‌های مشکوک قیمت.

## ۱۰. جدول `collection_log` (لاگ چرخه‌های جمع‌آوری داده)
پایش موفقیت و خطاهای دریافت داده در هر بار اجرای اسکریپت‌ها.
